# 我们的模型是什么

模型先看当时已结算的资金费、基差、价格、成交量、OI、现货/合约关系和跨所信息，再判断“会不会转负、是否能持续、三天后币到账时是否仍有合格机会”。它不是预测币价上涨的交易机器人。

## 固定结构

输入 x 共125维：90个基础/因果特征、26个现金周期/容量/跨所补充特征、9个条件到账数量特征。完整字段及顺序在 [FEATURES.json](../schemas/FEATURES.json)。主到账情景为1，0.5为条件敏感性情景，不能算两个独立事件样本。

三个事件头使用固定的 HistGradientBoosting 分类器，再用原校准器把原始分数校准成概率：

`p_h(x) = Calibrator_h(logit(HGB_h(x)))`

经济头是 hurdle 两阶段：先估计参考价值是否活跃，再回归其条件价值：

`V(x) = P(|Y|>1 USDT | x) × E[Y | active,x]`

| HGB固定参数 | 值 |
|---|---|
| max_iter | 100 |
| max_leaf_nodes | 7 |
| min_samples_leaf | 60 |
| learning_rate | 0.05 |
| l2_regularization | 10 |
| early_stopping | false |
| random_state | 20261109 |

参数和类别定义来自原冻结 `src/model.py`，运行时只调用predict；研究训练源码保留用于审计。三个概率目标与经济头定义见接口说明。

当前主模型没有稳定通过全部经济增益门槛；部分新增特征和跨所效果也不一致。保持原预先固定的模型，不根据测试最高分更换模型家族。观察性研究结果与正式策略保持独立版本。
